# Not a Jammer

Учебное приложение для Flipper Zero, демонстрирующее работу с Sub-GHz модулем.  
Программа **не является глушилкой** — она просто посылает короткие импульсы на выбранной частоте и позволяет тренироваться в разработке под Flipper.

# Программа написана для прошивки Xtreme (https://flipper-xtre.me/)

## Возможности

- Передача короткого burst-сигнала каждые 1 секунду (демо-режим).
- Регулировка рабочей частоты в Sub-GHz диапазоне.
- Выбор шага изменения частоты: **1 кГц, 10 кГц, 100 кГц, 1 МГц**.
- Простой интерфейс на экране Flipper:
  - `OK` — старт/стоп передачи;
  - `◄/►` — смена шага изменения частоты;
  - `▲/▼` — изменить частоту на ±текущий шаг;
  - `BACK (долгое)` — выход.
